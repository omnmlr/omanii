# Literature

**Corpus status: empty.** No literature search has been performed for this scaffold. Repository contracts are engineering context, not external validation. Never fabricate citations, dates, findings or claims of having read a source.

Keep one short entry per useful paper, technical source or official document. Link a verifiable original DOI/URL; distinguish peer-reviewed research, preprints, documentation and commentary. Record access/version information for changing sources. If only an abstract was available, say so and limit the interpretation.

## Source record

- **Citation/source:** Title, author/organization, venue/type and verifiable DOI/URL.
- **Publication date:** Revision date where relevant; mark unknown rather than guessing.
- **Research question:** What was investigated?
- **Method:** How was evidence obtained?
- **Experimental setup/dataset:** Devices, networks, environments, sample structure and access limits.
- **Primary result:** What the source reports; distinguish author claims from our interpretation.
- **Limitations:** Confounders, uncertainty, scope and transferability.
- **Relevance to OMANII:** The question, procedure or decision it may inform.
- **Category:** ADOPT / EXPERIMENT / WATCH / IRRELEVANT.
- **Confidence in our interpretation:** Low/medium/high with reason, read depth and reviewer/date.
- **Unanswered questions:** What requires checking or reproduction?

## Categories

| Category | Meaning |
| --- | --- |
| ADOPT | Suitable to inform a practice within existing scope; not approval to change production architecture, algorithms or measurement semantics. |
| EXPERIMENT | Promising but needs an OMANII-specific test. |
| WATCH | Relevant but immature, inaccessible or not currently actionable. |
| IRRELEVANT | Reviewed and not useful for the current question; preserve why to avoid repeat work. |

Prefer primary sources. Check whether endpoint, radio technology, device cohort and observation timescale fit OMANII's setting. Signal-strength research alone does not validate connection-quality recommendations.

First review priorities: separation of temporal/spatial variation, measurement dependence, stationary repeatability, device/orientation effects and independent verification of selected locations.
